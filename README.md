# 🛡️ SecurityGuard - Advanced Security & Activity Tracking App

একটি শক্তিশালী Android অ্যাপ্লিকেশন যা আপনার ফোনের সকল কার্যকলাপ ট্র্যাক করে এবং নিরাপত্তা প্রদান করে।

## ✨ বৈশিষ্ট্য

### 📊 ট্র্যাকিং ফিচার
- **স্ক্রিন টাইম**: প্রতিটি অ্যাপে কতটা সময় ব্যয় হয়েছে
- **লোকেশন হিসটরি**: আপনি কোথায় গেছেন এবং কতটা সময় ছিলেন
- **ক্যামেরা মনিটরিং**: অননুমোদিত ক্যামেরা অ্যাক্সেস ডিটেক্ট করা
- **অ্যাপ পারমিশন লগ**: কোন অ্যাপ কী পারমিশন ব্যবহার করছে
- **নেটওয়ার্ক মনিটরিং**: কোন অ্যাপ কী ডেটা পাঠাচ্ছে

### 🛡️ নিরাপত্তা বৈশিষ্ট্য
- সন্দেহজনক অ্যাপ ডিটেক্ট করা
- স্বয়ংক্রিয় সতর্কতা
- দুর্বল পারমিশন সনাক্তকরণ
- রিয়েল-টাইম মনিটরিং

### 📈 বিশ্লেষণ এবং রিপোর্ট
- দৈনিক সামারি
- সাপ্তাহিক বিশ্লেষণ
- উন্নতির সুপারিশ
- ডিটেইল গ্রাফ এবং চার্ট

---

## 📋 প্রয়োজনীয়তা

- Android 9 (API Level 28) বা তার উপরে
- Minimum 50MB স্টোরেজ স্পেস
- Permission: Device Administrator (সিকিউরিটির জন্য)

---

## 📥 ইনস্টলেশন গাইড

### পদ্ধতি ১: APK ফাইল থেকে (সহজ)

1. **APK ফাইল ডাউনলোড করুন**
   ```
   Releases পেজ থেকে SecurityGuard.apk ডাউনলোড করুন
   ```

2. **আপনার ফোনে ফাইল ম্যানেজার খুলুন**
   - ডাউনলোড ফোল্ডারে যান
   - SecurityGuard.apk খুঁজুন

3. **APK ফাইলে ট্যাপ করুন**
   - "ইনস্টল" বাটনে ক্লিক করুন
   - অ্যাপটি ইনস্টল হবে

4. **অ্যাপ খুলুন এবং পারমিশন দিন**

### পদ্ধতি ২: সোর্স কোড থেকে বিল্ড করা

#### Windows/Mac/Linux এ:

1. **Android Studio ডাউনলোড করুন** (ঐচ্ছিক)
   - অথবা অনলাইন বিল্ড সেবা ব্যবহার করুন

2. **রিপোজিটরি ক্লোন করুন**
   ```bash
   git clone https://github.com/robiulislam-org/SecurityGuard.git
   cd SecurityGuard
   ```

3. **বিল্ড করুন**
   ```bash
   ./gradlew assembleRelease
   ```

4. **APK পাবেন**
   ```
   app/release/app-release.apk
   ```

## ⚙️ পারমিশন সেটআপ

### Device Administrator অ্যাক্টিভেট করুন:

1. অ্যাপ খুলুন
2. **Settings** → **Admin Permissions**
3. **"Activate Admin"** বাটনে ক্লিক করুন
4. পপআপে **"Activate"** নির্বাচন করুন

### অন্যান্য প্রয়োজনীয় পারমিশন:

- **Location**: লোকেশন ট্র্যাকিংয়ের জন্য
- **Camera**: ক্যামেরা মনিটরিংয়ের জন্য
- **Storage**: ডেটা সংরক্ষণের জন্য
- **Phone**: কল লগের জন্য

**সব পারমিশন দিয়ে দিন সর্বোত্তম কর্মক্ষমতার জন্য।**

## 🐛 সমস্যা সমাধান

### অ্যাপ খুলতে পারছি না
- **সমাধান**: ফোন রিস্টার্ট করুন
- অথবা: Settings → Apps → SecurityGuard → Clear Cache

### লোকেশন ট্র্যাক হচ্ছে না
- **সমাধান**: Location Permission চালু করুন
- Settings → Permissions → Location → Allow

### স্ক্রিন টাইম দেখাচ্ছে না
- **সমাধান**: Device Administrator চালু করুন
- অ্যাপ → Settings → Activate Admin
